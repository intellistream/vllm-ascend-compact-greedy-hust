# Contributor instructions

The sole author/maintainer is Shuhao Zhang (ShuhaoZhangTony). Do not infer an advisor.

This is an experimental source mod. Preserve pinned base and postimage hashes; every runtime change needs a new mod version and independent numerical/API/performance evidence. Never inherit the legacy reduce-sample score.

Do not start services or access accelerators as part of source checks. Keep materializations, environments, caches and logs under /data/statecentric-builds on the development host. Use isolated environments; never overwrite a shared runtime. Preserve upstream license and attribution.
